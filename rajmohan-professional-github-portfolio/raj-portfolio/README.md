# Rajmohan Mangaonkar — Portfolio

Responsive, static professional portfolio built with HTML, CSS and JavaScript. No build step, dependencies or paid hosting required.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your actual GitHub username).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root and commit the changes.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and save.
4. After GitHub deploys the site, visit `https://YOUR_USERNAME.github.io/`.

For a repository with any other name, the URL will generally be `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`.

## Before sharing with recruiters
- Confirm the resume details and contact information are accurate and intended to be public.
- Add your verified LinkedIn and GitHub profile URLs if desired.
- Publish project code and replace the project notes with real repository/demo links. Do not add links to repositories that don't exist.
- Do not publish confidential employer materials or private datasets.

## Files
- `index.html`: content and page structure
- `styles.css`: responsive layout and theme
- `script.js`: mobile menu and copyright year
